# StudyBuddy
A student study planner with tasks, timetables, and progress tracking.

## Getting Started

From the actual project folder, run:

```bash
cd "C:\Users\DONA HENRY PINTO\OneDrive\Desktop\StudyBuddy-main\StudyBuddy-main"
npm install
npm run dev
```

Then open http://localhost:3000 in your browser.

## Included pages

- Home dashboard
- Weekly timetable
- Study progress overview

## Tech stack


- Next.js
- React
- Tailwind CSS
